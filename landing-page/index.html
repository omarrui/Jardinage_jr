Key Features

Service Request

Customers can submit gardening service requests through a simple form.

Admin Calendar

The administrator manages all appointments using an interactive calendar.

Secure Authentication

The system uses authentication and role-based access control for security.

About the Project

JR Jardinage was inspired by the need to simplify how customers schedule gardening services. Many small service providers still manage appointments manually, which can create confusion.

This project was built as a Portfolio Project for Holberton School. It allowed the development of a full-stack application using React, Flask, REST APIs, and database relationships.
