Key Features Fonctionnalités principales

Service Request Demande de service

Customers can submit gardening service requests through a simple form. Les clients peuvent envoyer des demandes de service de jardinage via un formulaire simple.

Admin Calendar Calendrier Admin

The administrator manages all appointments using an interactive calendar. L'administrateur gère tous les rendez-vous à l'aide d'un calendrier interactif.

About the Project À propos du projet

The Idea L'idée

This project was inspired by the need to simplify how customers schedule gardening services. Many small service providers still manage appointments manually, which creates confusion and inefficiency. Ce projet est né du besoin de simplifier la prise de rendez-vous pour les services de jardinage. De nombreux prestataires gèrent encore cela manuellement, ce qui crée confusion et inefficacité.

Building JR Jardinage Création de JR Jardinage

This project was developed as a Portfolio Project for Holberton School. It focuses on creating a clean, simple, and efficient system for managing appointments. Ce projet a été développé comme projet de portfolio pour Holberton School. Il vise à créer un système propre, simple et efficace pour gérer les rendez-vous.
